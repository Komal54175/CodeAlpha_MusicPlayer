# Music Player

A music player built with JavaScript as part of my **CodeAlpha Web Development Internship** (Task 4).

## Features
- Music player interface built with HTML and CSS
- Play, pause, next and previous controls using JavaScript
- Shows song title, artist and duration
- Progress bar and volume control
- ⭐ Playlist
- ⭐ Autoplay

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run Locally
1. Clone the repository:
   ```
   git clone https://github.com/Komal54175/REPO_NAME.git
   ```
2. Open `index.html` in your browser.
